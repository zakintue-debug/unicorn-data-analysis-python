# Unicorn Companies Data Analysis

**Python-based exploratory data analysis project focused on global unicorn companies.**

## Project Overview

This project explores a global unicorn-company dataset using Python. It demonstrates core data-analysis skills including data inspection, filtering, searching, exploratory analysis and visualisation, alongside an interactive Tkinter interface.

## Skills Demonstrated

- Python programming
- Data loading and inspection
- Data cleaning and filtering
- Exploratory data analysis
- Data visualisation
- Search and user-driven filtering
- Building a simple interactive desktop interface with Tkinter

## Repository Contents

- `NTU_XXXXX_SOFT40161_CourseWorkTemplate.ipynb` — analysis notebook and application logic
- `UNICORN.csv` — dataset used by the project

## Analytical Focus

The project is designed to explore patterns across unicorn companies and make the dataset easier to investigate interactively. It combines traditional notebook-based analysis with search/filter functionality and visual outputs.
